# Deep Blue Rescue

An underwater rescue game made with Babylon.js as a team project, with custom water and seashell
shaders, animated fish and Recast navigation.

Play it at https://deepbluerescuegame.onrender.com. The free server sleeps when idle, so the first
load can take a minute.

This repository holds the build that is deployed there.

## Run locally

```
npm install
npm run dev
```
